# Kidney Disease Classifier (Streamlit)
Files in the repo root: `app.py`, `requirements.txt`, `KIDNEY-Diseases.h5`
Run locally: `pip install -r requirements.txt && streamlit run app.py`
Deploy: push to GitHub → share.streamlit.io → New app → pick app.py.
In Advanced settings choose **Python 3.10 or 3.11** (TensorFlow 2.15 doesn't support newer).
